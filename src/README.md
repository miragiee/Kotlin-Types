# Типы данных
### Простые типы 
byte, short, int, long, double, float, boolean, char, string.
### Составные типы
pair, triple, array, list и др
    
*float/double z = 5.0*

*double z = 5 не будет работать, нужна дробная часть.*

*float требует суффикса F, float z = 15F;*
